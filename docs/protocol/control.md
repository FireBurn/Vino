# Control protocol

The D6000 has a plaintext opening phase, an HDCP 2.2 authentication exchange,
and a DisplayLink-specific encrypted control session. All shared counters and
session material have one owner.

## Plain initialization

The host performs the descriptor and vendor-control preamble, then sends three
plaintext messages without inserting waits between them:

1. `init_0`, type 1/subtype 0, empty body;
2. `init_25`, type 2/subtype `0x25`;
3. `init_4` concatenated with the HDCP channel probe.

The exact builders live in `proto.rs`; fixed bytes are covered by tests. Code
must not reconstruct these packets independently in callers.

## Encrypted messages

The inner control header is:

```text
u16 id
u16 subcommand
u16 inner counter
u16 reserved
```

Message builders in `cp.rs` own all offsets and accepted payload lengths. The
outer type-4 frame carries the wire sequence. Sealing uses the per-session
control key for AES-CTR and a DisplayLink CMAC over the nonce, big-endian wire
sequence, and ciphertext. Replies are decrypted and classified before their
payload is exposed.

The live control key is derived by XOR-whitening the SKE session key with the
fixed DisplayLink value documented beside `CP_KEY_WHITEN`. The raw SKE key is
what is wrapped for the receiver; the whitened value is used for control and
video-session construction.

## Per-head operations

Typed builders cover:

- downstream authentication and stream restatement;
- monitor presence, EDID engagement, readiness, and fetch;
- mode programming and stream markers;
- cursor create, image, and move;
- DDC/CI forwarding and readback;
- heartbeat and runtime status.

Mode-dependent words come only from a validated profile. Random tail bytes are
generated by the kernel RNG where the protocol treats them as opaque tokens.

## Transaction rule

Only the session owner advances the wire and inner counters. A caller cannot
send a control packet directly and report success when the session is absent.
KMS state is reconciled through the ordered control queue, and failures retain
the unapplied desired generation.
